# Statistical Data Normalization & Exploratory Data Analysis (EDA)

## Overview
This MATLAB project demonstrates foundational competencies in data preprocessing, array manipulation, and statistical data visualization. It benchmarks custom mathematical transformations against native algorithmic toolboxes to validate data integrity.

## Core Implementations
- **Stochastic Modeling:** Simulating and analyzing Gaussian (normal) and uniform distributions.
- **Signal Normalization:** Developing custom Z-score transformation algorithms used widely in neuroimaging (fMRI/EEG) preprocessing pipelines.
- **Advanced Visualization:** Engineering multi-panel data plots (`subplots`) to study the geometric effects of hyperparameter scaling (bin width) on frequency representation.
- **Descriptive Analytics:** Extracting distribution metrics (central tendency, variance, and IQR) from real-world temporal datasets (BU Hockey performance metrics).
